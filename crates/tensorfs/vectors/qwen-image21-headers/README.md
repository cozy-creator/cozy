# Qwen-Image-2.1 header evidence

These are metadata-only excerpts from the upstream revision recorded in MANIFEST.json.
The `.safetensors.header` files were modified by retaining only the eight-byte length and
JSON header; tensor payloads are omitted. Index JSON files are unmodified.
The full-file hashes and lengths are Hugging Face source declarations, not locally verified
payload hashes. Header digests are computed over the exact downloaded range bytes.
This evidence establishes geometry, not value correctness or inference quality.
